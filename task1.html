Task 0 - JavaScript Refresher

1. Variables and Data Types

const student = { name: "Aidana", age: 20, isActive: true, courses: ["Math", "CS101", "Physics"], address: { city: "Almaty", street: "Abay Ave" } }; let emptyValue = null; let notSet; const sentence = `${student.name} is ${student.age} years old and lives in ${student.address.city}.`;

let vs const: const can't be reassigned, let can. Neither works before its line runs.

typeof null: returns "object". It's an old bug in JS that never got fixed.

Primitive types: string, number, boolean, null, undefined, bigint, symbol.

2. Arrays

const nums = [3, 7, 2, 10, 5]; const doubled = nums.map(n => n * 2); const above5 = nums.filter(n => n > 5); const firstBig = nums.find(n => n > 5); const sum = nums.reduce((acc, n) => acc + n, 0); const has10 = nums.includes(10);

None of these change the original array, they all return new values.

3. Arrays of Objects

const students = [ { id: 1, name: "Alya", grade: 85 }, { id: 2, name: "Altyn", grade: 62 }, { id: 3, name: "Madina", grade: 91 }, { id: 4, name: "Serik", grade: 55 } ]; const passing = students.filter(s => s.grade >= 70); const names = students.map(s => s.name); const byId3 = students.find(s => s.id === 3); const top = students.reduce((a, b) => a.grade > b.grade ? a : b); const average = students.reduce((sum, s) => sum + s.grade, 0) / students.length; const withPass = students.map(s => ({ ...s, passed: s.grade >= 70 }));

withPass uses spread to build new objects instead of mutating the originals.

4. Objects

const user = { id: 1, name: "Nazyken", age: 20, address: { city: "Almaty", street: "Dostyk" } }; user.age = 21; user.email = "nazyken@gmail.com"; delete user.address.street; const { name, age } = user; const { address: { city } } = user; const { name: userName } = user;

5. Values and References

const original = { name: "Janerke", score: 10 }; const copy = original; copy.score = 99; // original.score also becomes 99, same object in memory const realCopy = { ...original }; realCopy.score = 50; // original stays the same this time, spread makes a new object const user = { name: "Janerke", address: { city: "Almaty" } }; const shallow = { ...user }; shallow.address.city = "Astana"; // user.address.city changes too, spread only copies one level deep const deep = { ...user, address: { ...user.address } };

copy.score changes original because objects are copied by reference, not by value.

Spread only copies the top level. The nested address object is still shared unless you spread it too.

6. Functions

function isEven(n) { return n % 2 === 0; } const isEvenArrow = n => n % 2 === 0; function getFullName(first, last) { return `${first} ${last}`; } const calculatePrice = (price, qty) => price * qty; const calculateDiscount = (price, pct) => price - (price * pct) / 100; const getMax = (a, b) => a > b ? a : b;

7. Functions as Values

const add = (a, b) => a + b; const multiply = (a, b) => a * b; function calculate(a, b, operation) { return operation(a, b); } calculate(5, 3, add); // 8 calculate(5, 3, multiply); // 15

Functions can be stored in variables and passed to other functions like any other value.

add is the function itself, add() calls it and gives back the result.

8. Scope

const message = "global"; function scopeDemo() { let message = "function"; if (true) { let message = "block"; } }

Global scope is visible everywhere. Function scope is visible only inside that function. Block scope is visible only inside its { }.

var ignores blocks and leaks out of them. let and const stay inside the block they were declared in.

9. Closure

function createCounter() { let count = 0; return () => ++count; } const counterA = createCounter(); const counterB = createCounter(); function createAdder(value) { return n => n + value; } const addFive = createAdder(5);

The inner function keeps access to variables from where it was created, even after the outer function finished running. That's a closure.

10. Destructuring, Spread and Rest

const numbers = [10, 20, 30, 40]; const [first, second] = numbers; const user = { id: 1, name: "Anna", age: 21 }; const { name, age } = user; const withExtra = [...numbers, 50]; const olderUser = { ...user, age: 22 }; const userWithEmail = { ...user, email: "anna@example.com" }; const combined = [...numbers, ...[1, 2, 3]]; const sum = (...nums) => nums.reduce((a, b) => a + b, 0); sum(1, 2); // 3 sum(1, 2, 3, 4); // 10

Spread expands a collection into separate items. Rest does the opposite, it gathers separate arguments into one array.

11. Optional Chaining and Default Values

const userA = { name: "Magzhan", address: { city: "Almaty" } }; const userB = { name: "Dana" }; userB.address?.city; userB.address?.city ?? "City not specified";

|| replaces any falsy value, even valid ones like 0 or "". ?? only replaces null or undefined, which is usually what you actually want.
